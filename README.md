# Final project

## Emotion Detector

An AI-based web application that detects emotions from text using Watson NLP.

### Features

- Detects anger
- Detects disgust
- Detects fear
- Detects joy
- Detects sadness
- Identifies the dominant emotion
- Flask web interface
- Error handling
- Unit testing
- Static code analysis

### Technologies

- Python
- Flask
- Watson NLP
- Requests
- unittest
- Pylint
